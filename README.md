# Women's Sports Hub

A full-stack web application for exploring and analyzing women's sports data.

The goal of this project is to make women's sports data more accessible through interactive visualizations, statistics, and analytics.

## 🚧 Project Status

This project is currently under active development.

### Current Progress

- React + Vite frontend set up
- TypeScript backend configured
- Express API server set up with minor functionality
- CORS configured for frontend/backend communication
- Prisma configured for database integration
- PostgreSQL database integration coming next

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript
- Prisma

### DB
- PostgreSQL
